# Single purpose statement

## Paste into dashboard

Ask Box lets users chat with the contents of their own Box (box.com) account. The user connects their Box account via OAuth; the extension indexes their Box files through our backend and answers the user's questions from that content in a side panel or popup. All features — Box sign-in, the file/indexing view, and the chat — serve this one purpose: asking questions of your own Box documents.
