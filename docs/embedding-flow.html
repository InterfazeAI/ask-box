Chunk embedding — sequential vs parallel

A file is split into chunks. Each chunk needs one embedding request. Both lanes obey the same 30 req/s rate limiter (visualized slower). Sequential waits for each round-trip before starting the next; parallel fires them all and lets the network latencies overlap — bounded by the rate cap, not by latency × chunks. Vectors reattach to their chunk by index.
